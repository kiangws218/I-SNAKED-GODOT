# Kenney 临时占位素材

这里仅保存游戏当前实际引用或即将接入的最小素材集合。完整 Kenney 2D CC0 原始库位于仓库外的 `D:\Kenney_CC0_2D_Library`，避免 Godot 导入数万份未使用资源。

来源：[Kenney Tiny Dungeon](https://kenney.nl/assets/tiny-dungeon)，版本 1.0，16×16，CC0 1.0。语义文件名是本项目的临时映射，不是 Kenney 的官方角色命名。
